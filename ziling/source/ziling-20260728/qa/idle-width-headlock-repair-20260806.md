# 紫灵待机尺度与头部稳定性修复

- 修复对象：`idle`。
- 原问题：待机轮廓约 74 像素宽，明显宽于修复后的 `jumping`；旧生成提示允许 head/body bob，连续播放出现轻微摇头。
- 修复设计：以已批准 `jumping` 动作条作为尺度与轮廓基准；头部、下巴、视线、发型外轮廓、躯干、双手和脚底基线全部锁定，仅保留轻微呼吸与一次缓慢眨眼。
- 行检查：6/6 帧提取成功，边界框宽度为 63-64 像素，高度与脚底基线一致；非透明像素范围为 `10436-10597`，无警告。
- 对比结果：`jumping` 边界框宽度为 64 像素，新 `idle` 与其视觉尺度一致。
- 独立视觉 QA：通过；动态播放仅见轻微呼吸与眨眼，头部、视线、角色尺度和脚底基线无跳变，首尾循环平滑。
- 影响范围：只重做标准动作第 0 行 `idle`；其他标准动作与 16 个 look directions 未修改。
- 旧版证据：原待机动作条、预览 GIF、扩展图集、联系表与验证报告均以 `pre-width-repair` 或 `pre-idle-repair` 文件名保留。
