# 李缨宁 look mechanics

李缨宁是持剑站立的人形桌宠。双脚、下身和脚底基线固定；暖棕色眼睛先带动视线，眼睑和眉形配合，随后头颈与上身做克制的俯仰或左右转动。禁止通过整张角色旋转、倾斜或拉伸来模拟观察方向。

持剑手保持与剑柄连接，带鞘长剑随腰部轻微转向但不换手、不跳位。暖阳宝玉始终由深色系绳连接腰甲，随身体转动产生连续的遮挡关系，不漂浮、不翻到错误一侧。双辫和两侧环髻只做轻微跟随。

- 000 / up：双眼明确上看，下眼睑略抬，眉眼上扬，抬下巴，额头与下颌底部略更可见；身体仍正面。
- 090 / screen-right：眼睛与鼻尖转向画面右侧，头颈轻微右转，画面左侧脸颊和灰白宽袖相对更可见；剑和宝玉仍连在腰侧。
- 180 / down：双眼明确下看，上眼睑压低，低头收下巴，发顶更可见；动作不同于摸宝玉，不抬手互动。
- 270 / screen-left：眼睛与鼻尖转向画面左侧，头颈轻微左转，画面右侧深青护臂与酒红胸甲相对更可见；剑和宝玉连续跟随。

每个 22.5 度中间方向都必须是相邻基准姿势的均匀插值。头部角度、眼睛、眼睑、鼻尖、辫子、剑和宝玉的位移要小而连续；不得出现单帧跳变、突然正脸、道具换侧、比例变化或脚底移动。
